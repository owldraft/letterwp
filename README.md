# LetterWP

Publish a post and it goes out as a beautiful email, through your own [Resend](https://resend.com) account. Your list stays in your own WordPress.

This is the free plugin. It is headed for the WordPress.org plugin directory; until it is listed, install it from this repository.

- **Your list, in your WordPress.** Subscribers live in your own database. CSV import from anywhere, CSV export any time.
- **Your brand.** Your logo, your colour, your domain. No plugin branding in your emails.
- **A beautiful email.** Blocks become inbox-safe HTML that works in Gmail, Apple Mail and Outlook.
- **Your own sending account.** Resend's free plan covers up to 1,000 contacts.

## Install

1. Download this repository as a ZIP (Code > Download ZIP), or `git clone` it into `wp-content/plugins/letterwp`.
2. In WordPress, go to Plugins > Add New > Upload Plugin, choose the ZIP, then activate.
3. Go to **LetterWP > Setup** and follow the steps.

Requires WordPress 6.5+ and PHP 7.4+. See [readme.txt](readme.txt) for features, FAQ and the external services it talks to.
